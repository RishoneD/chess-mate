# Chess-mate – ROADMAP

Source of truth for versions. The current version number is set in `version.py` and shown on screen.

## Versions

### v0.1 – Basic analysis (done)
- [x] Fetch the 10 most recent games from the public chess.com API (latest month, earlier months if needed), with a User-Agent
- [x] Game picker (default: latest): opponent, result, date, format
- [x] Stockfish analysis via python-chess, time budget of ~30 s (adjustable 15–60), with a progress bar
- [x] Advantage chart over the game, with mistakes marked
- [x] Inaccuracy / mistake / blunder classification by centipawn loss (50/100/200, eval capped at ±10, softened in decided positions), separately for me and the opponent
- [x] Short rule-based explanations: allowed mate, missed mate, lost piece/material, missed free capture, evaluation swing
- [x] "Copy summary": 3–5 critical moments (move, FEN, move played, best move, eval, explanation)
- [x] Phone layout: narrow screen

### v0.2 – English (done)
- [x] All UI, explanations, copy summary, code comments and docs in English (LTR layout)

### v0.3 – Good moves (done)
- [x] Every move gets a category: Great (only move) / Best / Excellent (loss ≤ 10) / Good (loss 11–49) / Inaccuracy / Mistake / Blunder
- [x] Great = played the engine's best move, the second-best was ≥ 150 cp worse, position not already decided (±5); recaptures and captures punishing an opponent's mistake are excluded
- [x] Engine runs MultiPV=2 for the second-best line (same time budget, ~1–2 plies less depth)
- [x] Counts table for all 7 categories (me / opponent), "Highlights" tab with my great moves, ★ on the chart
- [x] Copy summary includes up to 2 of my great moves

### v0.4 – Fixes and analysis quality (done)
- [x] Game times shown in local time (Asia/Jerusalem by default, `APP_TIMEZONE` to override)
- [x] Finished analyses kept server-side (up to 30), so a page reload does not re-run the engine
- [x] Engine crash / failure shows a clear message and a "Try again" button
- [x] Deterministic analysis: 1 thread + fixed node count per position, calibrated once per server process from the measured engine speed and rounded to fixed steps (same game → same result on the same server)
- [x] New explanations: piece left undefended, piece taken by a cheaper piece, allowed fork, allowed pin, missed fork
- [x] No inaccuracies flagged in the first 8 moves (no opening book); mistakes and blunders still are
- [x] "Only move" wording when every alternative allows mate

### v0.5 – Rename (done)
- [x] App renamed to "Chess-mate" (title, browser tab, footer, User-Agent, docs)

### v0.6 – Installable app (done; phone check pending)
- [x] Installable wrapper in `docs/` for GitHub Pages: full-screen iframe of the Streamlit Cloud app (`?embed=true`), with its own manifest, so Chrome on Android installs it as "Chess-Mate" with its own icon instead of "Streamlit"
- [x] Knight icon (192, 512, maskable 512, Apple touch), generated by `tools/make_icons.py`
- [x] Minimal service worker (no caching; the app needs a live connection)
- [x] The Streamlit app itself is unchanged and still works at its direct URL
- [ ] On the phone: install from the GitHub Pages URL and confirm the name and icon (cannot be verified from the computer)

### v0.7 – Summary for Claude, Format v2 (current)
The copy summary is read by Claude, not by a person: fixed line-oriented layout, every value labeled.
- [x] Stable header `Chess game analysis (chess.com) | Format: v2`; closing instruction line in Hebrew (answer in Hebrew, draw boards with red/green arrows, explain the missed idea and the principle)
- [x] Header block: my color and rating, opponent and rating, result, time control, date, link, accuracy per side, conventions line, full movetext (SAN, no clocks)
- [x] Up to 8 critical moments of mine, most severe first; each with phase (opening / middlegame / endgame), FEN, played vs best move (SAN + UCI), Eval and Win% before → after, tactic, 4-ply line after the move played and after the best move, clock
- [x] Classification by drop in win probability (lichess formula), thresholds 5 / 10 / 15 (inaccuracy / mistake / blunder); mate = 100% / 0%; a missed mate is always at least an inaccuracy; no separate "decided position" rule (the curve handles it); "great" = second-best ≥ 10% worse
- [x] All evaluations from my point of view (also when I play Black)
- [x] Tactic is either a rule-based finding (hanging piece, piece lost to a cheaper piece, fork, pin, allowed / missed mate, missed free capture, missed fork, lost piece / material) or "Not detected" (no generic guess); no material claims from engine lines shorter than 4 plies
- [x] Opponent's biggest mistakes I did not punish (up to 3): my reply was not best and gave back at least half of their loss, or was itself an inaccuracy or worse
- [x] Clock from `[%clk]`: time left before the move, time spent, opponent's time, TIME PRESSURE (< 10% of base time or < 30 s); "n/a" without clock tags or in daily games
- [x] Accuracy per side (lichess per-move formula; mean of arithmetic and harmonic means, no volatility weighting, so it differs slightly from lichess / chess.com)
- [x] "Copy summary" button in addition to the copy icon of the box
- [x] Clearer error when chess.com fails (user not found / service error / no connection), with "Try again"
- [x] Fixes: a mating move is no longer flagged as "missed mate" when the engine preferred another mate; a lost piece is no longer hidden by an unrelated trade in the line
